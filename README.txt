Firm Ground Homes: concept site (static)

Upload the contents of this folder to any web host. Open index.html to start.
No build step, no database. The only outside request is Google Fonts.
The sample forms run in the browser only: nothing typed is sent or saved.

Pages: index, about, programs, apply, referral, donate, volunteer, faq, impact, wishlist.
assets/styles.css  All styling. Colors, fonts and content width are variables at the top.
assets/dc-lite.js  Runs the sample forms. Keep it next to the pages.
